# QuickQuestion (screenask) - A lightweight AI

## setup:

1. Download as zip
2. Go to file location
3. Edit the file with IDLE and paste API key in and Save.
4. Open Requirements.txt, copy the line , open cmd and paste.

## usage

- basically upon opening, it will ask you to designate the region you want to be analysed/processed (picture a square and pick the top left and bottom right vertices  >> I recommend to try and squeeze only the necessary amount of space you need consistently as it reduces the amount of tokens spent per photo.
- press f9 (default hotkey) or your designated hotkey when you wish to get the answer

## lore / reason behind creation

My secondary school gave us chromebooks which were heavily restricted through google admin panel ,web extensions and evil browser restrictions (ie. no ai websites)
Then google gemini added a feature which basically built in an ai and was widely used by me and the rest of the school to skip questions on tests or homework.
It was great but I was really annoyed at how much I would get rate-limited by google as its was like 100 people firing requests for ai solutions at once which makes google sus wallah.
And so I made screenask to basically speed up how fast i do my homework lol, I mean it wasn't like the homework took me long but I just wanted a solution to get it done with quicker and this came to my mind.
